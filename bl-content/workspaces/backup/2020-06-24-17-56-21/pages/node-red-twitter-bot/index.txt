I have setup a new [Node-Red](https://nodered.org/) Twitter Bot. This is powered by a [Raspberry Pi 4 Model B (2GB)](https://deviwiki.com/wiki/RPF_Raspberry_Pi_4_Model_B_2GB) that I have setup as the new Pi Lab Node Red Node.

The [Node-Red](https://nodered.org/) flow is setup to provide a URL endpoint that accepts a minimal number of query parameters (e.g. hostname). The flow then makes http requests to the [Pi Lab Metric's Node](prometheus-grafana) that is powered by [Prometheus](https://prometheus.io/) to retrieve the metrics. The metrics are then formatted and pushed directly to the [Pi Lab Twitter feed](https://twitter.com/pilabdev).

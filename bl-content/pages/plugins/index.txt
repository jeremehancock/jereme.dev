These are plugins built specifically for Pi Lab.

## Show Node - Pi Lab
This plugin displays the current node in the sidebar of a [Bludit](https://bludit.com) installation on a server cluster. 

For more information on a setup that this plugin is intended for checkout [Pi Lab Setup](pi-lab-setup).

<a href="https://github.com/mhancoc7/show-node-pilab">
Download
</a>

-----

## Robots - Pi Lab
This plugin is a customized version of the  [Bludit](https://bludit.com) Robots plugin. It allows for adding a port to deny all for. This is useful when you have a special "dev" node setup on a different port.

<a href="https://github.com/mhancoc7/robots-pilab">
Download
</a>

-----

## Site Redirect - Pi Lab
This plugin allows you to temporarily redirect your site to another URL. The [Bludit](https://bludit.com) admin panel is still available. The frontend is also still accessible for administrators or editors.

<a href="https://github.com/mhancoc7/site-redirect-pilab">
Download
</a>

-----

## Web Stats - Pi Lab
Add your favorite web stats code (ex: [Statcounter](https://statcounter.com) to your website. You can also assign a port for your "dev" node so the stats code will not be used.

<a href="https://github.com/mhancoc7/web-stats-pilab">
Download
</a>

-----

## target='_blank' - Pi Lab
This plugin forces all external links on pages to open in new tabs.

</a>

## Version - Pi Lab
Show the current version on the sidebar of the admin panel, and check periodically for new Bludit releases. If there is a new release a link to the Bludit site will be displayed. If you are a Bludit PRO user a link to Bludit's Patreon page will be displayed.

<a href="https://github.com/mhancoc7/version-pilab">
Download
</a>

-----

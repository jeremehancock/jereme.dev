I have setup a new [Node-Red](https://nodered.org/) Twitter Bot. This is powered by a [Raspberry Pi 4 Model B (2GB)](https://deviwiki.com/wiki/RPF_Raspberry_Pi_4_Model_B_2GB) that I have setup as the new Pi Lab Node Red Node.

The [Node-Red](https://nodered.org/) flow was originally setup to provide a URL endpoint that accepts a minimal number of query parameters (e.g. hostname). The flow would then make http requests to the [Pi Lab Metric's Node](prometheus-grafana) that is powered by [Prometheus](https://prometheus.io/) to retrieve the metrics. The metrics were then formatted and pushed directly to the [Pi Lab Twitter feed](https://twitter.com/pilabdev).

I am now on version 4 of the flow. The latest iteration is completely self contained inside [Node-Red](https://nodered.org/). The flow runs every 30 minutes and does `ping` checks to ensure that the nodes are online before gathering the metrics for each node and sending out tweets. This allows me to reduce the overhead for each of the nodes in the Pi Lab cluster and have things more centralized. 

I have also added an SMS alert node that, after a failed `ping` check,  sends an email that is then forwarded via text message to my mobile phone using this [AT&T feature](https://www.att.com/support/article/wireless/KM1061254/).
